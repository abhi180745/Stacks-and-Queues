# Stacks-and-Queues
 C++ programs for Stack and Queue data structures
Stacks and Queues in C++

1. Introduction

This repository contains C++ programs demonstrating the implementation of Stack and Queue data structures using arrays.

2. Objectives

- To understand Stack and Queue data structures.
- To implement basic operations in C++.
- To learn Git and GitHub for version control.
- To maintain organized source code and documentation.

3. Programs Included

A. Stack ("stack.cpp")

A Stack follows the LIFO (Last In, First Out) principle.

Operations:

- Push: Insert an element.
- Pop: Remove the top element.
- Peek: Display the top element.
- Display: Show all elements.

B. Queue ("queue.cpp")

A Queue follows the FIFO (First In, First Out) principle.

Operations:

- Enqueue: Insert an element.
- Dequeue: Remove the front element.
- Display: Show all elements.

4. Repository Structure

Stacks-and-Queues/
├── stack.cpp

└── README.md

5. Requirements

- C++ compiler (such as g++)
- Git
- GitHub account

6. How to Compile and Run

Stack

g++ stack.cpp -o stack
./stack

Queue

g++ queue.cpp -o queue
./queue

On Windows, run "stack.exe" or "queue.exe" after compilation.

7. Testing

Test the programs by:

- Inserting and removing elements.
- Displaying the elements.
- Attempting to remove from an empty structure.
- Attempting to insert into a full structure.

8. Conclusion

This project demonstrates the basic operations of Stack and Queue data structures in C++. Git and GitHub are used to maintain and document the source code.
